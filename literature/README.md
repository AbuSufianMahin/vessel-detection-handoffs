# Paper notes

One Markdown file per paper, named `firstauthorYEAR-keyword.md` in lowercase, for example `smith2024-delegation.md`. Use the Better BibTeX citation key from Zotero as the name where possible, so notes and `\cite{}` keys match.

Only note what you have actually read. Claude uses these notes when writing the literature review, so a wrong note becomes a wrong sentence in the thesis.

## Template

```
# Short title

Citation key:
Read by: (initials), date
Method and sample:
Context (country, population):
Key findings relevant to us:
Limitations:
Which RQ or theme it supports:
Quotable numbers (with page):
```
