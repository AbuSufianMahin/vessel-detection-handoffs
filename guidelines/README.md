# Guidelines

Put your department's thesis guidelines here as Markdown (for example a transcription of the phase guideline slides and the submission checklist), so Claude can read them in Claude Code and in claude.ai Projects.

Tips:
- Transcribe every instruction, in the guideline's own order, and keep its examples marked as examples.
- When a new phase's guidelines arrive, add a new file instead of overwriting the old one, and update the `thesis-writing` skill so the rules stay in one place.
